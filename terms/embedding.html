向量嵌入 Embedding

一句話定義

把 token、圖片等資料轉成一串數字向量，意思相近的東西位置也相近。

白話比喻

像是替每個詞在「意義地圖」上標一個座標：「貓」和「狗」住得很近，「貓」和「股票」住得很遠。模型不懂文字，但很會算座標之間的距離與方向。

運作原理

  1. 建立嵌入表：準備一張「詞彙數 × 維度」的矩陣，每個 token ID 對應一列向量（例如 768 或 4096 維）。
  2. 查表：輸入的 token ID 直接取出對應那一列，得到向量序列。
  3. 跟著模型一起訓練：向量一開始是隨機的，訓練過程中被調整成能幫助預測的位置，語意相近的詞自然靠在一起。
  4. 比較相似度：用餘弦相似度等方法衡量兩個向量多接近，可用於搜尋、分類、推薦。

關鍵公式

cos(a, b) = (a · b) / (‖a‖ ‖b‖)

餘弦相似度只看兩個向量的「方向」是否一致，值越接近 1 代表意思越相近。

代表模型與應用

  • word2vec（2013）：經典詞向量模型，展示了「國王 − 男人 + 女人 ≈ 女王」這類向量運算。
  • CLIP（2021）：把圖片和文字嵌入到同一個空間，讓「文字找圖」與文字生圖的條件控制成為可能。
  • RAG 向量檢索：把文件切段轉成嵌入存進向量資料庫，提問時找出最相近的段落給 LLM 參考。

常見誤解

  • 誤解：向量的每一維都代表一個明確意義，例如第 3 維是「性別」。
    其實：意義通常分散在很多維度的組合中，單一維度大多無法直接解讀。
  • 誤解：同一個詞在 LLM 裡永遠是同一個向量。
    其實：只有輸入層的查表向量固定；經過 Transformer 後，「蘋果」在「吃蘋果」與「蘋果手機」中的表示會不同（上下文相關）。
