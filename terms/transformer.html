Transformer 架構 Transformer

一句話定義

以自注意力為核心、能平行處理整段序列的神經網路架構，是 LLM 的基礎。

白話比喻

舊的 RNN 像「傳話遊戲」，訊息必須一個人一個人往下傳，傳到後面就走樣了。Transformer 像一場「圓桌會議」，每個人都能同時聽到所有人的發言，再決定要重視誰的意見，又快又不容易遺漏。

運作原理

  1. 輸入嵌入 + 位置資訊：token 先轉成向量，再加上位置編碼，因為注意力本身不知道詞的先後順序。
  2. 多頭自注意力：每個 token 參考整段序列，融合上下文資訊。
  3. 前饋網路（FFN）：對每個位置各自做非線性轉換，加工剛融合的資訊。
  4. 殘差連接 + 正規化，堆疊 N 層：每個子層都有捷徑連線與 LayerNorm，讓深層網路穩定訓練；GPT 類模型可堆到數十層以上。
  5. 輸出：Decoder-only 模型（如 GPT）加上因果遮罩，只能看前文，輸出下一個 token 的機率分佈，一個一個生成。

關鍵公式

h = x + MultiHeadAttention( LayerNorm(x) )
y = h + FFN( LayerNorm(h) )

一個 Transformer 區塊就是「注意力 + 前饋網路」，各自外面包一層「加回原輸入」的殘差連接（此為常見的 Pre-LN 寫法）。

代表模型與應用

  • BERT（2018）：Encoder-only，擅長理解類任務，例如分類、問答。
  • GPT 系列（2018–）：Decoder-only，逐字生成文字，是 ChatGPT 等聊天機器人的基礎。
  • T5（2019）：Encoder-Decoder，把所有任務都當成「文字轉文字」。
  • ViT（2020）：把圖片切成小塊當 token，證明 Transformer 也能做影像辨識。

常見誤解

  • 誤解：Transformer 只能處理文字。
    其實：只要能切成序列就能處理，圖片（ViT）、聲音、影片，甚至擴散模型的去噪網路都有 Transformer 版本。
  • 誤解：Transformer = ChatGPT。
    其實：Transformer 是架構；ChatGPT 是在此架構上經過大規模預訓練、指令微調與人類回饋強化學習後的產品。
